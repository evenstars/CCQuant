# CCQuant 实施计划(里程碑速览)

详见 `docs/design.md` 第 8 节。每阶段都有可验证产物;核心目标是**先证明税后 alpha + 能机械执行**,而非短期收益。

| 里程碑 | 内容 | 产物 / Gate |
|---|---|---|
| **M0** 脚手架 (~0.5w) | 目录、配置、日志、数据缓存、测试骨架 | `pytest` 跑通空管线 |
| **M1** 数据层 (~1w) | 数据源接入、复权、历史成分股票池、流动性过滤 | 无幸存者偏差的历史数据 |
| **M2** 回测+策略 (~1.5w) | 12-1动量、选股、等权、趋势刹车、分批、t+1撮合、成本+税务建模 | 对照SPY/等权/MTUM报告;**Gate: 税后跑赢基准?** |
| **M3** 风控 (~0.5w) | 组合约束、断路器、防呆、wash-sale/持有期 | 风控单测全绿 |
| **M4** 实盘(IBKR Paper) (~1w) | ib_insync接入、diff下单、对账、幂等、kill switch | 纸上实盘≥1-2周期,对账无差 |
| **M5** 监控告警 (~0.5w) | 健康检查、邮件告警、dashboard、月报 | 调仓自动出报告+异常告警 |
| **M6** 小资金真实盘 (<$25k) | 切真账户、分批建仓、human-in-the-loop | 跑6-12月;**Gate: 实盘≈回测?** |
| **v2** TODO | 多空对冲、跨资产趋势、多因子、波动率目标、全自动 | 验证有alpha后 |

## 即时下一步(建议顺序)
1. 确认数据源选择(MVP yfinance vs 正式 Polygon/Norgate)。
2. M0 脚手架 + M1 数据层先行。
3. M2 出第一版回测报告,据税后结果决定是否继续。
